# Current i3/X11 inventory

Collected from `$HOME` on 2026-10-01. This is a snapshot for review; it does not declare that every listed item should stay in the final dotfiles.

## Active desktop configuration copied into this repository

| Live path | Purpose |
| --- | --- |
| `~/.xinitrc` | Starts i3 under xinit |
| `~/.config/i3/config` | i3 key bindings, startup commands, gaps, colored active borders, screenshots and display mode |
| `~/.config/i3status/config` | Existing i3status config; the currently active custom bar is Polybar |
| `~/.config/polybar/config.ini` | Main and date Polybar bars, per-workspace colors, tray, audio, network, memory and date modules |
| `~/.config/polybar/launch.sh` | Starts the main bar and date watcher, then hides the tray |
| `~/.config/polybar/fullscreen-watch.sh` | Starts the separate date capsule only when no i3 window is fullscreen |
| `~/.config/polybar` audio click action | Opens the standard Pavucontrol mixer |
| `~/.config/polybar/wifi-status.sh` | Polybar Wi-Fi status text |
| `~/.config/picom/picom.conf` | X11 compositor settings |
| `~/.config/rofi/theme.rasi` | Rofi application launcher theme |
| `~/.config/alacritty/{alacritty.toml,config.toml}` | Existing Alacritty configuration files |
| `~/.config/gtk-3.0/settings.ini` | GTK theme, icons and font settings |
| `~/.config/fastfetch/config.jsonc` | Fastfetch display settings |
| `~/.local/share/fonts/AdwaitaMonoNerdFont-{Regular,Bold}.ttf` | Locally installed interface fonts |

The repository preserves the optional py3status weather module for review; the i3status weather entry is commented out. The i3/Polybar configs keep the current display output and refresh rate. Sound uses Pavucontrol; network settings use NetworkManager's connection editor. Polybar workspace numbers have distinct bright colors, and the active i3 window keeps its blue border even when alone on a workspace.

## Other X11 files inspected

- `/etc/X11/xorg.conf.d/00-keyboard.conf` — system-generated US keyboard layout; i3 also starts `setxkbmap -layout us,ru -option grp:alt_shift_toggle`.
- `/etc/lightdm/lightdm.conf`, `/etc/lightdm/lightdm-gtk-greeter.conf`, `/etc/lightdm/users.conf` — system LightDM configuration. The optional `system/lightdm-gtk-greeter.conf` and `scripts/apply-lightdm-greeter.sh` manage the greeter file and save a timestamped backup.
- `/etc/xdg/autostart/nm-applet.desktop` and `picom.desktop` exist. i3 also starts `nm-applet` and Picom directly, so startup duplication should be reviewed later.
- `~/.config/autostart/Flameshot.desktop` points to `flameshot`, which was not in the explicit package list; not copied into the installer set.
- `~/.config/autostart/Outline-Client.AppImage.desktop` references `/opt/outline-client/Outline-Client.AppImage`; left out as a machine-specific third-party app path.
- The live Polybar config owns the system tray.
- `scripts/install-configs.sh` leaves `/etc` unchanged; `scripts/apply-lightdm-greeter.sh` writes only the LightDM GTK greeter config after backing up the previous file.

## Package snapshot

`packages/explicit-installed.txt` records the selected package set, omitting retired panel, tray, and interface packages, and `*-debug` split outputs. Normal package sources pull dependencies automatically. `packages/desktop-*.txt` is the smaller i3/X11 and audio/network profile. The `--all` installer profile includes unrelated software and lower-level system packages, so inspect it before use.
